Q1 · 导航守卫有哪些？完整执行顺序？

📌 场景

未登录访问 /project/list 要跳登录；已登录但没角色访问 /admin 要 403——守卫放哪？

查看答案

顺序（简化）：

  1. 导航触发
  2. 组件内 beforeRouteLeave
  3. 全局 beforeEach
  4. 路由独享 beforeEnter
  5. 组件 beforeRouteEnter
  6. 解析异步组件
  7. beforeRouteUpdate（同组件参数变）
  8. 全局 beforeResolve
  9. 导航确认 → afterEach

实践：登录校验放全局 beforeEach；页面标题、进度条放 afterEach。

Q2 · 动态路由怎么加？Vben Admin 菜单权限常见方案？

📌 场景

登录后后端返回菜单树和 permission 列表——前端怎么生成可访问路由？

查看答案
  1. 登录成功拿 roles / permissions / 菜单 JSON
  2. 用本地 asyncRoutes 模板 + filter 函数筛出有权限的路由
  3. router.addRoute() 动态注册（Vue Router 4）
  4. 生成侧边栏菜单（meta.title、icon、order）
  5. 404 路由最后 add，捕获未匹配
const accessRoutes = filterAsyncRoutes(asyncRoutes, permissions)
accessRoutes.forEach(r => router.addRoute(r))
router.addRoute({ path: '/:pathMatch(.*)*', redirect: '/404' })

注意：刷新页面需重新拉用户信息再 addRoute；登出 resetRouter() 移除动态路由。

Q3 · 路由懒加载原理？和代码分割什么关系？

📌 场景

管理后台 50+ 页面，首屏只想加载 Layout + 首页——怎么配？

查看答案 
{
  path: '/project',
  component: () => import('@/views/project/index.vue')
}

动态 import 触发 webpack/vite 代码分割，每个路由对应独立 chunk，访问时才下载。

优化：相关页面可合并 chunk（webpack magic comment webpackChunkName）；预加载 hover 菜单项 router.resolve + import()。

Q4 · 路由级权限和按钮级权限区别？前端权限能防黑客吗？

📌 场景

角色 A 能进人员列表但不能点「删除」；角色 B 连菜单都看不到——两层怎么配合？

查看答案
层级控制什么实现
路由级页面能否进入动态路由 + meta.roles
按钮级操作入口是否展示v-permission / 权限函数
接口级真正能否执行后端鉴权（必须）

结论：前端权限只为 UX（隐藏入口、减少误操作），不能替代后端。绕过前端直接调 API 仍须 403。

401/403 见 HTTP Q2。

Q5 · v-permission 指令怎么实现？

📌 场景

<el-button v-permission="'bpo:staff:delete'"> 没权限时 DOM 怎么处理？

查看答案 
function hasPermission(codes: string | string[]) {
  const perms = useUserStore().permissions
  const list = Array.isArray(codes) ? codes : [codes]
  return list.some(c => perms.includes(c))
}

app.directive('permission', {
  mounted(el, binding) {
    if (!hasPermission(binding.value)) {
      el.parentNode?.removeChild(el) // 或 el.style.display = 'none'
    }
  }
})

变体：支持 v-permission:all（需全部满足）；权限变更时 watch store 重新校验。

Q6 · 多标签页 + keep-alive + 路由怎么配合？

📌 场景

BPO 平台开多个考勤表单标签，切换保留填写状态，最多缓存 10 个——完整方案？

查看答案
  • tabsStore 维护 { path, title, name } 列表
  • keep-alive :include="cachedNames" :max="10"
  • 组件 defineOptions({ name: 'StaffForm' }) 与 include 匹配
  • 关闭标签从 include 移除，触发 unmount
  • router-view 的 key 用 fullPath 区分同组件不同参数

详见 Vue3 Q10。

Q7 · 路由传参：query / params / props 怎么选？

📌 场景

项目详情页要带 projectId，列表页筛选条件要可分享链接——用 params 还是 query？

查看答案
方式特点场景
query显式在 URL ?a=1，刷新保留筛选、分页、可分享
params（path）/user/:id 路径段RESTful 资源 id
props路由映射为组件 props解耦 route 对象
state（history）刷新可能丢临时大对象（慎用）

Q8 · 企业微信 OAuth2 单点登录和路由怎么衔接？

📌 场景

BPO 从企微工作台点进来，URL 带 code——前端路由守卫怎么处理？

查看答案
  1. 白名单路由 /oauth/callback 解析 code
  2. 调后端换 token，写入 store
  3. 拉用户权限 → 动态 addRoute
  4. next(redirect || '/') 进业务页

OAuth2 + JWT 见 HTTP Q5。
