Q1 · 业务组件封装：配置驱动、插槽、render 怎么选？

📌 场景

表格有的列要自定义渲染（状态标签、操作按钮），有的纯文本——抽象边界放哪？

查看答案
方式适用缺点
配置驱动80% 标准列、统一行为极端定制难表达
插槽 scoped slot列级自定义 cell模板略长
render / h()JSX 项目、动态列可读性看团队习惯

原则：80% 配置 + 20% 插槽 escape hatch；不要把所有业务逻辑塞进通用组件。

必练

Q2 · 如何把 el-table 改成配置式？要支持哪些能力？

📌 场景

BPO 平台 30+ 列表页，列定义、分页、loading 重复——你的 ProTable 封装了啥？

查看答案 
const columns = [
  { prop: 'name', label: '姓名', minWidth: 120 },
  { prop: 'status', label: '状态', slot: 'status' },
  { prop: 'action', label: '操作', fixed: 'right', width: 160 }
]

封装能力清单：

  • 动态列渲染、列显隐、本地持久化列配置
  • 分页联动（page/size/total → emit fetch）
  • loading、empty、selection 多选
  • 固定列、全屏、密度切换
  • scoped slot 透传 #status="{ row }"

数据流：父传 columns + requestApi，或受控 :data + @page-change。

Q3 · 通用弹窗组件：拖拽、嵌套表单、动态尺寸怎么设计？

📌 场景

业务弹窗有的 400px 表单，有的 90% 屏文件预览，还要能拖、吸边——API 怎么定？

查看答案 
<BaseDialog
  v-model:open="visible"
  title="编辑人员"
  width="520px"
  draggable
  :loading="submitting"
  @ok="handleSubmit"
>
  <StaffForm ref="formRef" />
</BaseDialog>

要点：

  • v-model:open 控制显隐；destroyOnClose 防状态残留
  • 拖拽：mousedown title 区 → 更新 transform，边界 clamp
  • 内容区 max-height + overflow-y: auto 独立滚动
  • 嵌套弹窗 z-index 栈管理；Esc 只关最上层
  • ok 前调子表单 validate()

Q4 · 响应式多条件查询组件怎么设计？

📌 场景

考勤筛选 8 个字段，1366 屏要自动换行，超出 2 行收起——实现思路？

查看答案
  • 配置数组 searchSchema：component、field、label、props
  • Flex + wrap + gap，每项 min-width
  • ResizeObserver 测高度，超阈值显示「展开/收起」
  • 统一 v-model:model 或 provide 表单上下文
  • 查询 / 重置 emit；重置恢复 defaultValues

类似 Vben Form、FormCreate 的 schema 驱动思想。

Q5 · 多格式文件预览组件架构？

📌 场景

合同归档要预览 PDF、Word、Excel、图片、视频——一个组件怎么分发？

查看答案 
FilePreview(url, mime)
  ├── ImageViewer（缩放旋转）
  ├── PdfViewer（pdf.js / 浏览器 embed）
  ├── OfficeViewer（微软在线预览 / 后端转 PDF）
  ├── VideoPlayer
  └── Fallback（下载链接）

优化：大 PDF 分页渲染；图片懒加载；预览 URL 用短期签名；错误态 + 重试。

Q7 · 表单组件封装：受控 vs 非受控？

📌 场景

封装 StaffSelect 给多个页面用——v-model 和内部缓存选项列表怎么平衡？

查看答案

受控：父传 modelValue + @update:modelValue，单一数据源。

非受控：内部 state + 初次 defaultValue，适合简单场景。

实践：业务组件默认受控；远程搜索 options 可内部缓存，value 仍受控；复杂表单用 Form 统一托管。

Q8 · 二次封装组件如何做版本兼容和文档？

📌 场景

团队 5 人共用 ProTable，有人直接改内部实现导致升级困难——怎么治理？

查看答案
  • 对外只暴露 props / events / slots 文档（Storybook / VitePress）
  • Breaking change 走 changelog + codemod
  • 内部依赖 UI 库版本锁在 peerDependencies
  • Monorepo 独立 packages/ui 发包或 workspace 引用
