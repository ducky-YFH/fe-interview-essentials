Q1 · ECharts option 核心结构？常见图表怎么配？

📌 场景

BPO 人力成本折线图 + 考勤异常饼图——option 里哪些字段必讲？

查看答案 
option = {
  title: { text: '人力成本趋势' },
  tooltip: { trigger: 'axis' },
  legend: { data: ['成本', '预算'] },
  xAxis: { type: 'category', data: months },
  yAxis: { type: 'value' },
  series: [{ name: '成本', type: 'line', data: [...] }]
}

核心：series 决定图表类型（line/bar/pie）；xAxis/yAxis 或 pie 的 radius；tooltip 交互提示。

Q2 · Vue 项目里怎么集成 ECharts？内存泄漏怎么防？

📌 场景

Vue2 BPO 统计页切换 Tab 再回来图表空白或重复——原因和正确写法？

查看答案 
mounted() {
  this.chart = echarts.init(this.$refs.chartRef)
  this.chart.setOption(option)
  window.addEventListener('resize', this.handleResize)
},
beforeDestroy() {
  window.removeEventListener('resize', this.handleResize)
  this.chart?.dispose()
}

要点：

  • 容器必须有明确宽高
  • setOption 更新数据；主题切换 dispose 后重建
  • Vue3 用 onMounted/onUnmounted + shallowRef 存实例
  • Tab 隐藏时用 v-show + 切换后 chart.resize()

Q3 · 图表和筛选条件怎么联动？

📌 场景

选部门、日期范围后，折线图和柱状图同时刷新——数据流怎么设计？

查看答案
  1. 筛选组件 emit filterChange 或共享 Pinia/Vuex state
  2. 父组件 / composable 调统计 API 拿新 data
  3. 各 chart 实例 setOption({ series: [{ data }] }, { notMerge: false })
  4. loading：chart.showLoading() / hideLoading

优化：防抖筛选；多个图表同一接口返回多 series 一次 setOption。

Q4 · 数据量大时 ECharts 怎么优化？

📌 场景

考勤明细 10 万点折线渲染卡死——有哪些手段？

查看答案
  • 后端聚合：按天/周汇总后再画（首选）
  • dataZoom：区域缩放，默认只显示一段
  • sampling：'lttb' / 'average' 降采样
  • large / progressive：大数据量模式
  • 按需加载：钻取时再请求明细

Q5 · 窗口 resize、Sidebar 折叠后图表变形怎么办？

📌 场景

左侧菜单收起，图表区域变宽但图还是旧的窄尺寸——

查看答案
  • window.addEventListener('resize', () => chart.resize())
  • Sidebar 动画结束后再 resize（transitionend）
  • ResizeObserver 监听容器 DOM 尺寸变化（更精准）
  • 防抖 resize 回调，避免频繁触发

Q6 · 数据钻取和下钻怎么实现？

📌 场景

点击柱状图某月，进入该月各部门明细——交互怎么接？

查看答案 
chart.on('click', (params) => {
  const month = params.name
  fetchDetail(month).then(data => {
    chart.setOption(detailOption(data))
  })
})

配合面包屑「返回上级」；或路由跳转到明细页带 query 参数。
