Q1 · 前端直传 OSS 和服务端中转怎么选？

📌 场景

摄影师一次上传 5000 张底片，每张 20MB——文件不经业务服务器，直接进 OSS/Kodo，为什么？

查看答案
方式优点缺点
直传对象存储 带宽不进业务机、可断点续传、CDN 就近 需凭证管理、回调校验
服务端中转 权限简单、易做病毒扫描 服务器带宽/内存瓶颈、大文件超时

常见架构：前端向后端要短期上传凭证 → 直传 OSS → OSS 回调或前端通知后端落库。

必练

Q2 · 预签名 URL / STS 凭证流程？Secret 能放前端吗？

📌 场景

Monorepo 里有人把 OSS Secret 写进 .env 给 Vite 用——对吗？正确流程是什么？

查看答案

正确流程：

  1. 前端带 token 请求后端 /upload/token
  2. 后端用 Secret 签发短期 STS / PostPolicy / 预签名 URL（限定 bucket、路径前缀、过期时间）
  3. 前端用凭证直传，过期重新申请
  4. 上传成功后把 objectKey 提交后端关联业务记录

绝不能：OSS AccessKey Secret 进前端 bundle（任何人可反编译拿走）。

见 工程化 Q8。

必练

Q3 · 秒传（MD5 / ETag）怎么实现？

📌 场景

同一张 JPG 重复上传，希望跳过实际上传——前端和后端各做什么？

查看答案
  1. 选文件后计算 hash（MD5 / SHA-256 / SparkMD5 分块读大文件）
  2. 调 checkFile 接口传 hash + 大小 + 文件名
  3. 后端查是否已有相同 object → 有则返回已有 URL（秒传成功）
  4. 无则返回 uploadId / 凭证，走正常上传

注意：大文件 MD5 用 Web Worker 避免卡 UI；Electron 可在 worker_threads 算；hash 碰撞极低但业务可再加 size 校验。

必练

Q4 · 分片上传和断点续传怎么做？

📌 场景

单文件 200MB RAW，弱网传到一半断了——怎么续传而不是从头来？

查看答案
  1. 文件切成固定大小 chunk（如 5MB）
  2. 后端/init 接口返回 uploadId
  3. 逐片上传，带 partNumber + uploadId
  4. 本地记录已成功的 part 列表（IndexedDB / localStorage）
  5. 中断后 listParts 或读本地进度，只传缺失片
  6. 全部完成后调 complete 合并

前端：每片独立重试；complete 前校验片数完整；取消时调 abort 清理服务端碎片。

二、任务中心 & 工程实践

必练

Q5 · 批量上传：并发控制、进度、取消、重试怎么设计？

📌 场景

100 张图同时传会打满带宽和连接数——你的任务中心怎么限流？用户点取消呢？

查看答案
  • 并发池：最多 N 个 in-flight（如 3～6），完成一个再取下一个 → 并发 Q5
  • 进度：单文件 xhr/fetch onProgress + 总进度 = Σ(已传字节)/总字节
  • 取消：AbortController 绑每个请求；队列里 pending 任务标记 cancelled 跳过
  • 重试：指数退避 + 最大次数；仅对网络/5xx 重试，4xx 不重试
  • 失败隔离：单文件失败不阻塞队列，汇总失败列表支持「仅重传失败项」
必练

Q6 · 上传任务中心架构怎么拆？

📌 场景

底片上传要：压缩、MD5、秒传、凭证、进度、重试——Pinia + EventEmitter 怎么组织？

查看答案 
UploadQueue（调度）
  ├── UploadTask × N（状态机：pending→hashing→uploading→done/fail）
  ├── ConcurrencyPool（max=3）
  ├── CredentialService（取/刷新 OSS 凭证）
  └── HashWorker（MD5 计算）

Pinia uploadStore：任务列表、总进度、全局 pause/resume
UI：任务中心面板订阅 store + 事件

状态机：idle → hashing → checking（秒传）→ uploading → success | failed | cancelled

压缩：上传前 canvas / wasm 压 JPEG quality，权衡清晰度与体积。

EventEmitter 模式见 手写 Q8。

选练

Q7 · 多存储兼容（OSS / Kodo）前端怎么抽象？

📌 场景

平台管理后台可切换对象存储厂商——上传模块怎么避免 if/else 满天飞？

查看答案

定义 StorageAdapter 接口：

interface StorageAdapter {
  getCredential(file: FileMeta): Promise<Credential>
  upload(file: File, cred: Credential, opts: UploadOpts): Promise<Result>
  abort(taskId: string): void
}

各厂商实现差异（PostPolicy vs 分片 API）封装在 adapter 内；业务只调统一 uploadFile()。

Q8 · Electron 本地上传和 Web 上传差异？

📌 场景

Electron 扫本地目录批量上传，Web 用 input 选文件——共用队列层要注意什么？

查看答案
  • Electron 可读目录路径 + 流式读文件，不必先读进内存
  • MD5 可在主进程 worker 算，见 Electron Q6
  • Web 只有 File/Blob，无真实路径
  • 队列层统一抽象为 { name, size, readStream(): ReadableStream }
  • 大文件 Electron 注意内存；Web 注意浏览器并发连接数限制（同域约 6）
