一、盒模型 & BFC

必练

Q1 · 标准盒模型和 IE 盒模型区别？

📌 场景

全局 * { box-sizing: border-box } 后，设 width: 100% 的输入框不再撑破父容器——为什么？

查看答案
  • content-box（默认）：width 只含内容，padding/border 额外加宽
  • border-box：width 包含 padding + border，更直觉

项目普遍重置为 border-box，避免宽度计算踩坑。

必练

Q2 · BFC 是什么？能解决什么问题？

📌 场景

两栏布局：左侧 float 的图片把右侧文字绕排了，想让右侧形成独立区域——BFC 怎么用？

查看答案

BFC（块级格式化上下文）：独立布局区域，内外互不影响。

常见触发：overflow: hidden/auto、display: flow-root、float、absolute、flex/grid 子项等。

能解决：

  • 清除内部 float（父高度塌陷：overflow: hidden 或 clearfix）
  • 阻止 margin 折叠（见 Q3）
  • 自适应两栏（右侧 overflow: hidden 避开 float）
必练

Q3 · 外边距折叠（margin collapse）是什么？

📌 场景

上下两个 margin: 20px 的 div，间距不是 40px 而是 20px——原因？

查看答案

相邻块级元素垂直外边距相遇时取较大值（非相加）。

避免：父元素形成 BFC、用 padding 代替、flex/grid 布局。

选练

Q4 · position 几种值区别？

查看答案
  • static 默认，不定位
  • relative 相对自身原位置偏移，占位保留
  • absolute 相对最近非 static 祖先，脱流
  • fixed 相对视口
  • sticky 滚动到阈值前 relative，之后 fixed

二、Flex & 居中

必练

Q5 · Flex 主轴 / 交叉轴对齐常用属性？

📌 场景

工具栏：左 logo、中间搜索、右头像——用 Flex 怎么排？

查看答案 
.toolbar {
  display: flex;
  align-items: center;      /* 交叉轴垂直居中 */
  justify-content: space-between; /* 主轴两端分布 */
}
.search { flex: 1; margin: 0 16px; } /* 中间占满剩余 */

记忆：justify-content 管主轴，align-items 管交叉轴；flex: 1 均分剩余空间。

必练

Q6 · 水平垂直居中至少说 3 种？

查看答案 
/* 1. Flex（最常用） */
.parent { display: flex; justify-content: center; align-items: center; }

/* 2. Grid */
.parent { display: grid; place-items: center; }

/* 3. 绝对定位 + transform */
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

已知宽高还可用 margin: auto + absolute 四向 0。

选练

Q7 · Grid 和 Flex 怎么选？

查看答案
  • Flex：一维（行或列），内容驱动，导航/工具栏
  • Grid：二维行列，布局驱动，仪表盘、相册网格

猫咔底片墙：Grid repeat(auto-fill, minmax(120px, 1fr)) 自适应列数。

三、层叠 & 实战

必练

Q8 · z-index 为什么不生效？层叠上下文

📌 场景

Modal 设了 z-index: 9999 仍被父级里的下拉盖住——可能原因？

查看答案

z-index 只在同一层叠上下文内比较。

创建新层叠上下文：position + z-index、opacity<1、transform、filter、flex 子项等。

解法：Modal 挂到 body（Teleport），脱离父级上下文。

选练

Q9 · 移动端 1px 边框、安全区怎么处理？

查看答案
  • 1px：伪元素 + transform scaleY(0.5)、border-image
  • 安全区：padding-bottom: env(safe-area-inset-bottom)
  • 小程序 / H5 底部 Tab 适配刘海屏
选练

Q10 · Tailwind 类名方案和传统 CSS 如何取舍？

📌 场景

猫咔用 Tailwind，BPO 用 Sass 模块——面试怎么评价原子化 CSS？

查看答案

Tailwind 优点：快、设计 token 统一、Tree-shaking 未用类、少起名。

缺点：模板类名长、复杂动画/伪元素可读性差。

实践：业务页 Tailwind + 少量组件 scoped CSS；设计系统组件可 @apply 封装。

必练

Q11 · SCSS 常用特性？和 CSS Modules 怎么配合？

📌 场景

BPO 用 Sass 模块化管理变量和 mixin——面试能说出哪些实用特性？

查看答案
  • 变量 / 嵌套 / &父选择器
  • mixin：@include flex-center 复用
  • @use / @forward（替代 @import，避免重复注入）
  • 函数：颜色 lighten/darken

CSS Modules：Vue <style module> 生成唯一类名防冲突；SCSS 写逻辑，Modules 管作用域。

必练

Q12 · 移动端 rem / vw 适配方案？

📌 场景

H5 要在 375 设计稿上还原，小程序用 rpx——各怎么换算？

查看答案

rem：根 font-size = 屏幕宽/10（flexible）或 postcss-pxtorem 把设计稿 px 转 rem。

vw：1vw = 1% 视口宽，375 设计稿 100vw = 375px，用 postcss-px-to-viewport。

小程序 rpx：750rpx = 屏幕宽，375px 屏上 1rpx = 0.5px。

注意：1px 边框、安全区另处理，见 Q9。
