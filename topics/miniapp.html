Q1 · 小程序双线程模型是什么？setData 为什么慢？

📌 场景

选片列表一次 setData 传 500 张图片元信息，页面卡 2 秒——根因和优化方向？

查看答案

双线程：

  • 逻辑层（JSCore）：跑 JS，调 setData
  • 渲染层（WebView）：跑 WXML/WXSS，负责 DOM
  • 两层通过 Native 桥通信，setData 要序列化 + 跨线程传输 + diff 渲染

setData 慢的原因：数据量大、频率高、深层路径多、同时触发大量节点更新。

优化：

  • 只传变化字段，避免整表替换
  • 合并多次 setData（下一帧统一更新）
  • 分页 / 虚拟列表，控制 WXML 节点数
  • 非视图数据放普通变量，不进 data

Q2 · 页面和组件生命周期顺序？和 Vue 怎么对应？

📌 场景

从订单页返回选片页要刷新列表但不丢滚动位置——该用 onShow 还是 onLoad？组件里呢？

查看答案

页面：onLoad → onShow → onReady → onHide → onUnload

组件：created → attached → ready → detached

场景用哪个
首次进页拉详情onLoad（读 query）
从子页返回刷新onShow
DOM 就绪后测尺寸 / 初始化 CanvasonReady / ready
页面销毁清定时器onUnload / detached

UniApp：统一为 Vue 生命周期 + 页面级 onLoad/onShow 等，条件编译处理平台差异。

Q3 · 小程序登录授权流程？token 怎么存？

📌 场景

猫咔小程序：用户打开要先登录，后续请求带 token——标准流程和注意点？

查看答案
  1. wx.login() 拿临时 code（5 分钟有效）
  2. 前端把 code 发后端，后端调微信 code2Session 换 openid + session_key
  3. 后端签发业务 JWT / 自定义 token 返回前端
  4. 前端存 storage，请求头携带

注意：

  • session_key 不能下发前端
  • 用户信息获取需 getUserProfile / 头像昵称填写能力（政策常变）
  • token 过期走静默 login 或引导重新授权
  • 与 Web JWT 拦截器思路一致，见 HTTP Q5

Q4 · UniApp 条件编译和多端差异怎么处理？

📌 场景

同一套代码要跑微信小程序和 H5，支付、分享、文件 API 各端不同——怎么组织？

查看答案 
// #ifdef MP-WEIXIN
wx.requestPayment({ ... })
// #endif
// #ifdef H5
// 跳转 H5 收银台
// #endif

最佳实践：

  • 业务逻辑放 composables，平台能力走 adapter 接口
  • 差异大的模块按平台分包，避免主包过大
  • 样式用 rpx + 安全区变量；H5 注意 rem 基准
  • API 统一封装 uni.request，内部处理 header / 错误码

Q5 · 微信小程序支付流程？前端职责边界？

📌 场景

客户选片后下单支付——前端要调哪些 API？哪些参数绝不能前端自己算？

查看答案
  1. 前端创建订单 → 后端调微信统一下单 API
  2. 后端返回支付参数（timeStamp、nonceStr、package、signType、paySign）
  3. 前端 wx.requestPayment 唤起收银台
  4. 结果以后端回调 + 主动查单为准，前端 success 只作 UI 提示

边界：商户密钥、签名、金额校验全在后端；前端防重复点击、展示 loading、失败重试查单。

幂等设计见 HTTP Q1。

Q6 · 订阅消息怎么用？和模板消息区别？

📌 场景

精修完成要通知客户——怎么让用户授权订阅并在后端触发推送？

查看答案

流程：

  1. 用户触发场景时调 wx.requestSubscribeMessage，选模板 id
  2. 用户同意后，后端在业务发生时调「发送订阅消息」接口
  3. 一次授权通常对应一次发送（长期订阅需特定类目）

注意：不能强制授权；拒绝后要有站内信 / IM 等兜底；模板内容需微信审核。

Q7 · 小程序长列表、大量图片怎么优化？

📌 场景

猫咔小程序：3000 张选片缩略图 + IM 聊天长历史——你用了 z-paging、懒加载，还能说哪些？

查看答案
  • 分页加载：z-paging / 自研上拉加载，控制单次 setData 量
  • 图片：缩略图 CDN、lazy-load、webp、占位图
  • 虚拟列表：只渲染视口节点（recycle-view / 自定义）
  • 分包：主包 < 2M，非首屏功能 subPackages
  • 预加载：preloadRule 提前下载分包
  • 缓存：列表数据内存缓存 + 返回页 onShow 增量刷新
  • 避免：wxml 深层嵌套、频繁 bindtap 里 setData 整表

Web 侧虚拟列表见 渲染 Q9、Vue3 Q11。

Q8 · Canvas 图片涂鸦：坐标、缩放、合成怎么做？

📌 场景

自研 Canvas 工具：网络图本地化、双指缩放、画笔、撤销重做、合成保存——关键技术点？

查看答案

基础：

  • 网络图先 downloadFile 或 getImageInfo 转本地路径（避免 canvas 跨域 taint）
  • 高清屏：canvas.width = cssWidth * dpr，ctx.scale(dpr, dpr)
  • 双指缩放：记录 pinch 中心、scale 矩阵变换， redraw 底图 + 笔迹层

笔迹：touchstart/move/end 采样点，quadraticCurveTo 平滑；笔迹存数组支持 undo/redo。

合成：drawImage 底图 → 叠加路径 → canvasToTempFilePath 导出。

性能：离屏 canvas 缓存静态层；拖动时只重绘笔迹层；限制导出分辨率。

Q10 · 小程序和 Web 共用 Monorepo 怎么拆？

📌 场景

shared-api、shared-types 三端复用，但小程序不能直接用 axios / DOM API——边界在哪？

查看答案
  • 可共享：纯 TS 类型、枚举、工具函数、业务状态机、错误码映射
  • 需适配：HTTP 客户端（uni.request vs axios）、存储、文件、支付
  • 不可共享：直接操作 window/document 的代码、Electron IPC
  • 用 shared-api 定义接口 + 各端 adapter 注入 transport

Monorepo 结构见 Vue3 Q12、工程化 Q6。
