一、输出题（Q1-Q10）

选练

Q1 · 以下分别输出什么？

const fn1 = () => { 42 };
const fn2 = () => 42;
console.log(fn1());
console.log(fn2());
查看答案

undefined, 42

  • 块体 {} 里没有 return
  • 表达式体隐式 return
选练

Q2 · 输出什么？

const calc = (a, b) => (a + b, a * b, a - b);
console.log(calc(3, 4));
查看答案

12（3 * 4）

括号里是逗号表达式，值为最后一项 a * b。

选练

Q3 · 输出什么？

const getUser = () => ({ name: 'Alice' });
const broken = () => { name: 'Bob' };
console.log(getUser());
console.log(broken());
查看答案

{ name: 'Alice' }, undefined

  • broken 的 {} 是函数体，没有 return
  • getUser 用 () => ({}) 才是返回对象

Q4 · 输出什么？

const obj = {
  name: 'obj',
  regular() {
    console.log(this.name);
  },
  arrow: () => {
    console.log(this.name);
  },
};
obj.regular();
try {
  obj.arrow();
} catch (e) {
  console.log(e.message);
}
查看答案

'obj'，然后 TypeError（Node 严格模式：外层 this 为 undefined，读 this.name 报错）

  • regular 的 this 是 obj
  • arrow 继承外层 this，不指向 obj
选练

Q5 · 输出什么？（Node 环境）

const obj = {
  name: 'inner',
  show: () => console.log(this.name),
};
try {
  obj.show();
} catch (e) {
  console.log(e.message);
}
查看答案

TypeError（Node 严格模式外层 this 为 undefined）

箭头函数不绑定 obj，this 来自定义处外层。

Q6 · 输出什么？

const obj = {
  count: 0,
  inc: () => {
    this.count++;
  },
  incRegular() {
    this.count++;
  },
};
try {
  obj.inc();
} catch (e) {
  console.log('inc:', e.message);
}
obj.incRegular();
console.log('count:', obj.count);
查看答案

inc 报错（Cannot read properties of undefined），count: 1

  • inc 改外层 this.count
  • incRegular 正确修改 obj.count

Q7 · 输出什么？

function Foo() {
  this.val = 1;
  this.getVal = () => this.val;
  this.getValRegular = function () {
    return this.val;
  };
}
const f = new Foo();
const getVal = f.getVal;
const getValRegular = f.getValRegular;
console.log(getVal());
try {
  console.log(getValRegular());
} catch (e) {
  console.log(e.message);
}
查看答案

1，然后 TypeError: Cannot read properties of undefined (reading 'val')

  • 箭头函数 getVal 词法绑定创建时的实例 f
  • getValRegular 独立调用 this 丢失
选练

Q8 · 输出什么？

const obj = {
  items: [1, 2, 3],
  print() {
    this.items.forEach(function (n) {
      console.log(n, this);
    });
  },
  printArrow() {
    this.items.forEach((n) => {
      console.log(n, this === obj);
    });
  },
};
obj.printArrow();
查看答案

依次 1 true, 2 true, 3 true

forEach 的箭头回调继承 printArrow 的 this（即 obj）。

Q9 · 输出什么？

var i = 0;
const fns = [];
for (var i = 0; i < 3; i++) {
  fns.push(() => console.log(i));
}
fns[0]();
fns[1]();
fns[2]();
查看答案

3, 3, 3

  • var 没有块级作用域
  • 箭头函数闭包共享同一个 i；循环结束后 i === 3

Q10 · 输出什么？

const obj = {

二、报错题（Q11-Q15）

必练

Q11 · 下面哪行会报错？报什么错？

const Person = (name) => {
  this.name = name;
};
// A
const p = new Person('Tom');
// B
console.log(Person.prototype);
// C
Person.call({ name: 'Jerry' });
查看答案
  • A 报错 TypeError: Person is not a constructor
  • B 输出 undefined（箭头函数无 prototype）
  • C 不报错但无法改变 this，仍用外层 this
选练

Q12 · 下面会怎样？

const bar = () => {
  console.log(arguments);
};
bar(1, 2, 3);
查看答案

ReferenceError: arguments is not defined（严格模式顶层箭头函数）

选练

Q13 · 下面会怎样？

sayHi();
const sayHi = () => console.log('hi');
查看答案

ReferenceError: Cannot access 'sayHi' before initialization（TDZ，const 不提升）

选练

Q14 · 能否通过编译？若不能，原因是什么？

const gen = *() => yield 1;
查看答案

语法错误，箭头函数不能作 Generator（不能写 function* 也不能 *() =>）。

必练

Q15 · 输出什么？bind 能改变箭头函数的 this 吗？

const obj = { n: 100 };
const fn = () => console.log(this?.n);
const bound = fn.bind(obj);
bound();
查看答案

undefined

bind 不能改箭头函数已绑定的 lexical this。

三、改错&手写（Q16-Q20）

必练

Q16 · 计时器为什么 count 一直是 NaN？如何改一行修复？

const counter = {
  count: 0,
  run() {
    setInterval(function () {
      this.count++;
      console.log(this.count);
    }, 100);
  },
};
counter.run();
查看答案

setInterval 回调里 this 不是 counter。

修复：

setInterval(() => { this.count++; ... }, 100);

Q17 · 只改 handler 的定义，让下面打印 'myApp'

const app = {
  name: 'myApp',
  run() {
    const handler = function () {
      console.log(this.name);
    };
    handler();
  },
};
查看答案 
const handler = () => console.log(this.name);

Q18 · 手写 createMultiplier

📌 要求
  • createMultiplier(5)(3) === 15
  • createMultiplier(2)(10) === 20
查看答案 
const createMultiplier = f => n => n * f;

Q19 · 用箭头函数一行实现数组去重

📌 要求

输入 [1, 2, 2, 3, 1]，输出 [1, 2, 3]（ES6，不用 Set 也行）

查看答案 
arr.filter((v, i, a) => a.indexOf(v) === i)

或 [...new Set(arr)]（若允许 Set）

选练

Q20 · 实现 compose，要求箭头函数写法

📌 要求
  • compose(f, g)(x) === f(g(x))
  • 例：compose(x => x + 1, x => x * 2)(3) === 7
查看答案 
const compose = (f, g) => x => f(g(x));

四、概念题（Q21-Q25）

必练

Q21 · 箭头函数和普通函数有哪些核心区别？至少说 4 点

查看答案

无 own this / 无 arguments / 不能 new / 无 prototype / 无 hoisting（const）等

选练

Q22 · 为什么 React 类组件里推荐写 this.handleClick = () => {} ？

查看答案

保证回调里 this 指向组件实例，且每次 render 不必 bind。

选练

Q23 · 对象字面量里哪些场景应该用普通方法，哪些场景适合箭头函数？

查看答案

需要 this 指对象 → 普通方法；定时器/回调要捕获外层 this → 箭头函数。

选练

Q24 · 下面说法对错？简要说明

  • (a) 箭头函数没有 prototype
  • (b) 箭头函数可以用 new 调用
  • (c) 箭头函数的 this 在定义时确定，普通函数在调用时确定
  • (d) DOM 点击事件若需要 event.currentTarget，应优先用箭头函数
查看答案
  • (a) 对
  • (b) 错
  • (c) 对
  • (d) 错，DOM 需要 this 指向元素时用普通函数
选练

Q25 · Vue 2 选项式 API 里，methods 里为什么一般不用箭头函数定义方法？

查看答案

箭头函数 this 不指向 Vue 实例，this.xxx 访问不到 data/methods。
