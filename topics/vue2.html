Q1 · Vue2 响应式原理？和 Vue3 Proxy 比缺什么？

📌 场景

BPO 表单动态加字段 this.form.extra = {} 视图不更新——为什么？

查看答案

Vue2 用 Object.defineProperty 递归劫持已有属性 get/set，依赖收集 + 派发更新。

局限：

  • 新增/删除属性检测不到 → Vue.set / this.$set
  • 数组下标/length 需 hack（重写 push 等方法）
  • 初始化时要递归遍历，大对象有成本

Vue3 Proxy 对比见 Vue3 Q2。

Q2 · Vue.set 什么时候必须用？数组哪些写法不触发更新？

📌 场景

this.list[0] = newItem 和 this.list.splice(0, 1, newItem) 哪个可靠？

查看答案

对象：this.$set(this.obj, 'newKey', val)

数组：用变更方法 push/pop/splice/sort... 或 $set(arr, index, val)

不触发更新：直接索引赋值 arr[i]=x、改 length。

Q3 · Vue2 生命周期顺序？和 Vue3 Composition 怎么对应？

📌 场景

created 里调接口还是 mounted？beforeDestroy 要清什么？

查看答案

顺序：beforeCreate → created → beforeMount → mounted → beforeUpdate → updated → beforeDestroy → destroyed

Vue2Vue3 Composition典型用途
createdsetup()调 API、初始化数据
mountedonMountedDOM 操作、ECharts init
beforeDestroyonUnmounted清定时器、dispose 图表
activatedonActivatedkeep-alive 恢复

created 无 DOM；需要 $el 的操作放 mounted。

Q4 · Vuex 有哪些核心概念？mapState 怎么用？

📌 场景

BPO 全局用户信息和权限在 Vuex——组件里怎么优雅取值和提交 mutation？

查看答案

五件套：state、getters、mutations（同步）、actions（异步）、modules

...mapState(['user']),
...mapGetters(['permissions']),
...mapActions(['fetchUser'])

规范：改 state 只走 mutation；异步在 action 里 commit。

Q5 · mixin 有什么问题？Vue2 项目里你怎么替代？

📌 场景

多个页面 mixin 了同一个 logMixin，data 重名、钩子顺序难排查——

查看答案

mixin 问题：命名冲突、来源不透明、多 mixin 钩子合并顺序难维护。

替代：

  • Vue2.7+ / Vue3：composables
  • 高阶组件 / 插槽
  • Vuex module 共享状态

原型链与 mixin 见 原型链 Q10。
