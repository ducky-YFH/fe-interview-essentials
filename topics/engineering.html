Q1 · Vite 和 Webpack 本质区别？

📌 场景

猫咔新项目用 Vite，老 BPO 用 Webpack——面试问为什么 Vue3 生态更常选 Vite？

查看答案
ViteWebpack
开发启动原生 ESM，按需编译先打包再启动 dev server
热更新精确 HMR，快全量/模块链，大项目慢
生产构建底层 Rollup自身打包体系
配置约定优于配置，插件生态灵活但配置复杂

口述：「开发阶段 Vite 利用浏览器 ESM 不打包，冷启动快；生产仍要打包优化，用 Rollup。」

必练

Q2 · Vite 开发环境为什么快？

📌 场景

改一个 Vue 组件，Vite 几乎秒更新；Webpack 大项目要等几秒——原理差在哪？

查看答案
  1. 入口 index.html 直接引用 <script type="module">
  2. 浏览器请求哪个模块，Vite 才编译哪个（esbuild 预构建 node_modules）
  3. 不需要先把整个依赖图打成 bundle 再启动
  4. HMR 只替换变更模块边界，保持状态

Q3 · 生产构建会做哪些优化？

📌 场景

打包后 assets/index-a1b2c3.js 文件名带 hash——构建流水线里发生了什么？

查看答案
  • Tree Shaking 删除未使用导出
  • 代码压缩（Terser/esbuild）
  • 代码分割（dynamic import → 多个 chunk）
  • 资源 hash 文件名 → 长缓存（见 缓存 Q5）
  • CSS 提取、图片压缩、Legacy 插件（可选）
必练

Q4 · 路由懒加载 / 代码分割怎么做？

📌 场景

管理后台 50+ 路由，首屏不想全打进一个 3MB 的 bundle——怎么拆？

查看答案 
// Vue Router
{
  path: '/orders',
  component: () => import('./views/Orders.vue'),
}

// Webpack 魔法注释（可选命名 chunk）
import(/* webpackChunkName: "orders" */ './Orders.vue')

原则：按路由/弹窗/重型图表库拆分；公共依赖抽 vendor chunk；注意 chunk 过多也有 HTTP 开销（HTTP/2 缓解）。

Q5 · Loader 和 Plugin 区别？（Webpack）

查看答案
  • Loader：文件转换器（sass→css、ts→js、vue→js）
  • Plugin：扩展构建生命周期（HtmlWebpackPlugin、DefinePlugin、压缩）

口诀：Loader 处理模块内容，Plugin 处理打包流程。

Q6 · Monorepo 解决什么问题？pnpm workspace 怎么用？

📌 场景

猫咔：Web、Electron、小程序、shared-api 在一个仓库——为什么不上 multirepo？

查看答案

收益：共享代码一处改、类型统一、原子提交、依赖提升省磁盘。

// pnpm-workspace.yaml
packages:
  - 'apps/*'
  - 'packages/*'

// apps/web 引用
"dependencies": {
  "@moka/shared-api": "workspace:*"
}

注意：边界清晰（packages 不互相乱依赖）、CI 可按变更包构建、版本发布策略（changesets）。

与 Vue3 Q12 分层思路一致。

Q7 · ESLint + Prettier 怎么分工？

查看答案
  • ESLint：代码质量（未使用变量、hooks 规则、import 顺序）
  • Prettier：纯格式化（缩进、引号、换行）
  • 用 eslint-config-prettier 避免规则冲突
  • husky + lint-staged 提交前检查

Q8 · 环境变量 .env 怎么用？哪些不能暴露？

📌 场景

Vite 里 VITE_API_BASE 配接口地址，有人把 OSS Secret 也写进 .env——行吗？

查看答案
  • Vite 只有 VITE_ 前缀会暴露给客户端代码
  • .env.development / .env.production 分环境
  • 绝不能进前端 bundle：数据库密码、OSS Secret、私钥
  • 敏感操作走后端签名接口（上传凭证短期有效）

Q9 · Source Map 是什么？生产环境开不开？

查看答案

映射压缩后代码到源码，便于 Sentry 等定位错误行。

  • 生产可 hidden-source-map：上报平台可用，浏览器不暴露给用户
  • 不要公开完整 source-map 到 CDN，防源码泄露
选练

Q10 · 开发代理 proxy 解决什么？和 Nginx 反代关系？

📌 场景

vite.config.ts 里 server.proxy 把 /api 转到后端——和跨域专题什么关系？

查看答案

开发时浏览器请求同源 localhost:5173/api，Vite 转发到真实后端，绕过浏览器 CORS 限制。

生产用 Nginx 反代或后端 CORS，见 跨域 Q6。

Q11 · UI 组件库按需加载怎么配？

📌 场景

Vue3 + Vite 项目只用 10 个 Ant Design Vue 组件，打包却很大——

查看答案 
// vite.config.ts
import Components from 'unplugin-vue-components/vite'
import { AntDesignVueResolver } from 'unplugin-vue-components/resolvers'

Components({
  resolvers: [AntDesignVueResolver({ importStyle: 'less' })]
})

效果：模板里用到的组件自动 import + 样式按需。

Element Plus / Vant 同理；Webpack 时代用 babel-plugin-import。

二次封装见 组件封装 Q6。
